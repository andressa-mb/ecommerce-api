## E-commerce API

API RESTful desenvolvida para simular o backend de uma plataforma de e-commerce.
O projeto implementa funcionalidades essenciais de um sistema de vendas online.  

Este projeto foi desenvolvido com foco em boas práticas de arquitetura backend, organização de código e segurança em APIs.

#### Sobre o projeto

A aplicação segue padrões REST e foi construída para servir como backend para aplicações frontend ou integrações externas.

#### Funcionalidades
- API REST para gerenciamento de pedidos (orders)
- Operações CRUD de pedidos (orders)
  - Criar pedidos
  - Listar pedidos
  - Atualizar pedidos
  - Remover pedidos
- Estruturação de endpoints seguindo padrão REST
- Tratamento de erros e respostas HTTP padronizadas

#### Testes

- Testes automatizados utilizando Jest
- Cobertura de cenários de erro da API
- Testes de endpoints REST
- Validação de respostas HTTP e mensagens de erro

#### Tecnologias utilizadas

- Express
- Node
- Rest API
- Mongoose
- Jest
- Git
